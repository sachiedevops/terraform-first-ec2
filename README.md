# Terraform First EC2

A beginner Terraform project that creates **one Ubuntu 22.04 EC2 instance** in AWS.

## What this project does

1. Configures the HashiCorp AWS provider.
2. Finds the latest Canonical Ubuntu 22.04 LTS AMI in `us-east-1`.
3. Creates one `t3.micro` EC2 instance in the AWS account's default VPC.
4. Prints the instance ID and public IP.

## Project files

- `main.tf` — Terraform configuration.
- `.gitignore` — prevents local Terraform state and working files from being committed.
- `.terraform.lock.hcl` — generated by `terraform init`; commit it after initialization.

## Requirements

- Terraform installed.
- AWS CLI installed and authenticated.
- An AWS identity with permissions to describe AMIs and create, describe, and terminate EC2 instances.
- AWS region set to `us-east-1`.

Use an appropriately scoped IAM identity for learning. Do not use the AWS root identity for routine infrastructure work. Never commit AWS access keys, secret keys, session tokens, passwords, or private SSH keys.

## Run the project (PowerShell)

Open PowerShell in the project directory:

```powershell
cd C:\Terraform\first-ec2
terraform init
terraform fmt
terraform validate
terraform plan
terraform apply
terraform output
```

Review the plan before applying. Type `yes` only if you approve creating the EC2 instance and any associated charges.

## Delete the resources after the lab

When finished, run:

```powershell
terraform destroy
```

Review the destroy plan and type `yes` to confirm. Verify in the EC2 console that the instance has been terminated.

## Important notes

- `terraform plan` previews changes; it does not create resources.
- `terraform apply` creates the EC2 instance and can incur charges, including compute, EBS storage, and public IPv4 charges.
- `terraform destroy` removes resources tracked by this Terraform state.
- This beginner example uses the default VPC and does not create a custom VPC, subnet, security group, or SSH key pair.
- This configuration does not open SSH access. Do not assume you can SSH into the instance.
- Keep `.terraform/` and `terraform.tfstate*` out of Git; state can contain sensitive infrastructure details.
